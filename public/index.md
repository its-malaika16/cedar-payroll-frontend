# Cedar Payroll

Cedar Payroll is UK payroll software for employers, bureau staff, and employees. Run pay, file RTI with HMRC, issue payslips, manage leave and attendance, and let staff use a self-service portal. The same login works on the web, iPhone, and Android.

## Product

- Payroll processing and HMRC compliance
- Payslips, P11, P45, P60, P11D, and PBIK
- Employee records, leave, rota, and clock-in
- Bureau tools for accountants and payroll firms
